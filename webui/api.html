API reference

One canonical version: /api/v1/*. No unversioned aliases.

Interactive docs: Swagger UI · schema: /api/v1/openapi.json · health: /healthz and /readyz.

Conventions

201 Created and 202 Accepted responses include a Location header.

Errors are {"detail": "..."}: 409 for duplicates/invalid run state, 403 for path escapes, 400 for bad input.

Lists return envelopes such as {"projects": [...]}; runs include {"run": …, "tool_calls": […]}.

SSE example

const s = new EventSource(
  '/api/v1/runs/' + runId + '/events?after=0'
);
s.addEventListener('message.delta', e => {
  const d = JSON.parse(e.data);
  console.log(d.content, 'seq=', e.lastEventId);
});
