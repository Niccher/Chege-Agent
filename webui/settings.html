Choose a save mode
How saving works. Apply now changes only this running process and is lost on restart. Save as defaults applies the change immediately and writes it to data/settings.json, so it is reloaded on every restart. Clear saved defaults removes that file; the next restart returns to your .env values. API keys are stored with 0600 permissions and are always masked in responses.
