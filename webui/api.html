Canonical local base URL: http://127.0.0.1:8001/api/v1 · interactive docs: Swagger UI · schema: /api/v1/openapi.json · health: /healthz and /readyz · tool governance UI: /tools.

Conventions

201 Created and 202 Accepted responses include a Location header.

Errors are {"detail": "..."}: 409 for duplicates/invalid run state, 403 for path escapes, 400 for bad input (including an unknown tool name on PATCH /tools/{tool_name}).

Lists return envelopes such as {"projects": [...]} and {"tools": [...]}; runs include {"run": …, "tool_calls": […]}.

SSE example (replay-safe)

const s = new EventSource(
  '/api/v1/runs/' + runId + '/events?after=0'
);
// EventSource reconnects with Last-Event-ID; the server replays
// from that sequence (no lost or duplicated events).
s.addEventListener('run.phase', e => {
  const d = JSON.parse(e.data);
  console.log(d.label, d.step + '/' + d.max_steps);
});
s.addEventListener('message.delta', e => {
  const d = JSON.parse(e.data);
  console.log(d.content, 'seq=', e.lastEventId);
});

GET /tools response shape

GET /api/v1/tools
{
  "tools": [
    {
      "name": "tool_name",
      "description": "Technical description sent to the model",
      "purpose": "Plain-language purpose shown in the UI",
      "risk": "read",
      "enabled": true,
      "grant_mode": "none"
    }
  ]
}

PATCH /api/v1/tools/{tool_name}
{"enabled": false, "grant_mode": "prompt_once"}

risk is one of read, write, exec, network; grant_mode is none or prompt_once. All 20 tools default to enabled=true, grant_mode=none.

Defaults and file-tree examples

GET    /api/v1/settings           → masked current settings
PUT    /api/v1/settings/defaults  → apply + persist to data/settings.json
DELETE /api/v1/settings/defaults  → clear saved defaults

GET /api/v1/files/tree?project_slug=js-calculator&max_depth=8&max_nodes=500
{
  "root": ".",
  "nodes": [
    {"name": "src", "path": "src", "type": "directory",
     "children": [{"name": "app.js", "path": "src/app.js", "type": "file"}]}
  ],
  "truncated": false,
  "node_count": 2
}

directory nodes have children; symlink nodes are shown but never traversed. max_depth is 1–32 and max_nodes is 10–5000.

SSE event types

run.phase payload: {"phase", "label", "step", "max_steps"}. Labels are fixed and server-authored (e.g. "Preparing workspace", "Planning step N of M", "Waiting for the model", "Reviewing the response") — never model-generated.

run.started, run.phase, message.delta, thinking.delta, tool.started, tool.output, tool.completed, tool.approval_required, tool.ask_user, todo.updated, run.completed, run.failed, run.cancelled.
