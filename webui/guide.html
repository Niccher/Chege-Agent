How it works

From a prompt to verified changes in your workspace.

The short version: the browser talks to a versioned REST API; the API starts an asynchronous run; the agent loop calls tools inside a sandboxed workspace; results stream back over SSE; you approve risky steps and inspect the diff.

The five-step lifecycle

Lifecycle

1 · Project

POST /api/v1/projects creates a slug, a workspace under workdir/ and a Git repository with an initial commit.

2 · Session

A project has threads (sessions). Each thread stores messages, todos and the conversation history.

3 · Run

POST /api/v1/runs returns 202 Accepted. Before any work begins, an automatic checkpoint snapshot is taken.

4 · Stream & approve

GET /runs/{id}/events streams token deltas, thinking deltas, tool starts/results and approval requests.

5 · Inspect & revert

Browse files, read the diff, commit, or POST /runs/{id}/revert to return to the pre-run snapshot.

Approval policies

ModeBehaviour
auto_editOrdinary file writes run automatically; destructive writes, shell commands (except exact safe commands), network and process tools ask first.
ask_allEvery non-read tool pauses for confirmation.
full_autoNo prompts at all. Only use this in a throwaway workspace.

Tool families

Files: read, write, edit, delete, list.

Execution: run commands, start/watch/stop background processes.

Git: status, diff, log, commit.

Search & web: grep, fetch, search.

Memory & planning: project brain, todos, ask-user.

Streaming events you will see

EventMeaning
run.startedThe agent loop accepted the run.
message.deltaA chunk of the assistant reply.
thinking.deltaModel reasoning, shown in a muted panel.
tool.started / tool.completedA tool was invoked and its (truncated) result returned.
tool.approval_requiredThe run is paused; approve or reject in the chat.
run.completed, run.failed, run.cancelledTerminal state; the stream closes.
Tip: reconnecting a stream uses ?after=<last event id>, so a page refresh does not lose output. Prompt injection is the main adversary in a no-auth local app — read the safety model.
