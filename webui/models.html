How selection works

Applies to new runs

Your selection is saved immediately to data/settings.json and used for every new run — no extra save step needed.

  • llama.cpp: choosing a model restarts llama-server on the host, then the new model is used immediately.
  • Ollama: choosing a model tag is instant — Ollama switches per request.
  • You can still override the model per run in the Playground's model selector.
  • Other defaults (provider URLs, sandbox, context size) are managed in the Settings console.
