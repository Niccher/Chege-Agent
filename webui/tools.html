Safety model
How control works. Every tool is on by default. Turning one off removes it from the model's tool list and blocks it at execution time. Grant prompt makes the agent ask you before it may use a tool in a given run; you approve it once per run. Dangerous actions (delete, kill, commit) always need confirmation regardless of these switches. Changes take effect for the next tool call — no restart needed.

Grant modes explained

No grant

The tool is available as soon as the run starts, subject to the run's approval policy (auto_edit by default; ask_all or full_auto selectable). Governance still applies — disabling a tool always blocks it, even under full_auto. Good for everyday tools you trust.

Grant prompt

Before the first use in a run, the agent pauses and asks you to allow the tool. Your approval is recorded for that run only, then the tool can be used normally within it. A new run asks again.
