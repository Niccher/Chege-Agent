Personal · Local-only · No login

An AI coding agent that works in your workspace,
not just in your chat window.

Chege Agent creates project workspaces, talks to your local model, runs tools with streaming output, asks before risky commands, and lets you inspect every diff and roll back with one click.

Runs on 127.0.0.1. Your code never needs a cloud account.
Project workspaces

Each project gets an isolated folder and its own Git repository.

Live streaming

Watch tokens, reasoning and tool results arrive over Server-Sent Events.

Approval gates

Safe edits auto-run; destructive or shell actions wait for your OK.

Automatic checkpoints

Every run starts with a snapshot, so revert is always available.

Full setup guide
Local by design

There is deliberately no login, no users and no tenants. The port is bound to 127.0.0.1; for remote use, connect over an SSH tunnel. Read the safety model before enabling full_auto.

Built on a versioned API

Everything the UI does is available through /api/v1/* — use Swagger or your own scripts.

API reference Swagger UI

Questions?

Does it need internet? No — local model and vendored UI assets.

Can I use OpenAI? Yes, set a key in settings and select the provider.

Can I expose it publicly? Don't. Use a tunnel and the loopback binding.
